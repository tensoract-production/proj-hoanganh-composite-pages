# Cấu hình GitHub Pages cho tài liệu HAC

Trang công khai của sơ đồ vận hành nhà máy Hoàng Anh Composite, dựng để khách xem mà không cần tài khoản GitHub: https://tensoract-production.github.io/proj-hoanganh-composite-pages/

Repo public này chỉ nhận file đã xuất bản; nội dung nguồn không được chỉnh sửa tại đây. Nội dung là bản chỉ xem, dựng tự động từ ứng dụng `diagrams/operating-flow/` của repo `tensoract-production/proj-hoanganh-composite-docs` qua workflow `publish-operating-flow`. Bản này không sửa được sơ đồ, không có trang hồ sơ và ghi chú.

Không sửa tay ở đây. Mỗi lần phát hành, nhánh `main` bị ghi đè bằng một commit mới nên mọi thay đổi tại chỗ sẽ mất. Muốn đổi sơ đồ thì sửa ở repo docs rồi push `main`.
